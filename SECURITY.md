# Security policy

## Report a vulnerability

Do not open a public issue for a vulnerability.

Report it privately, in one of two ways:

1. Use **"Report a vulnerability"** on the [Security tab](https://github.com/apiable/keelie-sdk/security) of this repository.
2. Send an email to **security@apiable.io**.

Tell us what you found, how to reproduce it, and which version it affects. We confirm that we
received it, and we tell you when a fix is released.

## Supported versions

No version of the SDK is released yet. When one is, this section names the versions that get
security fixes.
